# 前端重设计与迁移路线

更新日期：2026-11-10。状态：Vue 前端与四个工作区已实现；开发者启动 Vite 后由用户验收视觉和交互，反馈后继续迭代。

## 1. 已确认方向

- 前端采用 Vue 3 + TypeScript + Vite，单独开发服务器通过代理调用现有 FastAPI API。
- 生产构建由 FastAPI 同源托管；普通使用仍只需启动 FastAPI。
- 本轮不重写后端领域服务、接口、数据模型或业务规则。
- 旧原生页面的视觉与布局方案整体效果未获认可，不作为新版实施规范；业务保护规则继续有效。
- 文字模拟面试已经闭环；逐轮后台分析、长期记忆和语音仍未实现。

## 3. 架构边界

- 开发环境：Vite 在 `127.0.0.1:5173` 运行，代理现有 API 到 FastAPI；开发页面入口是 `/`。
- 构建环境：静态构建产物由 FastAPI 在 `/app/` 提供；`/frontend-assets/` 是生产资源前缀，不是开发页面入口。
- 数据：业务数据只存后端数据库；不使用浏览器存储代替持久层。
- 接口：沿用现有 REST 与 SSE 契约，保留 revision、幂等请求、回答 ack 和状态恢复语义。
- 安全：资料原文按文本安全呈现；不得执行材料中的指令或让模型改写用户原文。
- 旧入口：新版未构建时，FastAPI 仍回退到 `src/interview_assistant/web/`；是否移除在用户验收后决定。
- 语音：目前没有录音、转写、音频流或播报 UI，需另行完成产品与后端协议设计。

## 4. 用户验收重点

由用户启动服务体验，不主动运行构建、测试、静态检查或浏览器验证。重点观察：长答案和代码阅读、筛选与分类、PDF/OCR 结果核对、项目证据引用、计划生成及确认、由计划开始面试、回答保存确认、SSE 断线恢复、窄屏布局和键盘操作。按项目约定，本轮交付只报告实际执行的动作，不声称未执行的验证已通过。
